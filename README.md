# 💰 お金の生産性を振り返るアプリ

毎月の支出の中で、**生産性が高かった買い物を3つ振り返る**ためのシンプルなアプリです。

## 📖 使い方

1. **対象月を入力** — 例：「2026年6月」
2. **3つの買い物を記録**
   - 品目
   - 金額（円）
   - 生産性が高いと感じた理由
3. **「クリップボードにコピー」をクリック**
4. **Google Keep に貼り付け**

## ✨ 特徴

- ✅ シンプルで使いやすい UI
- ✅ クリップボードに自動整形して出力
- ✅ Google Keep との連携に最適化
- ✅ オフライン動作（インターネット接続不要）

## 🚀 クイックスタート

### ローカルで使う
```bash
# ファイルをダウンロードして、ブラウザで開く
open money-productivity-app.html
```

### オンラインで使う（デプロイ）
このアプリは **静的 HTML** なので、以下のどこでも無料でホスト可能：

- **Netlify** — ドラッグ&ドロップでデプロイ
- **Vercel** — GitHub と連携して自動デプロイ
- **GitHub Pages** — 設定メニューで有効化するだけ
